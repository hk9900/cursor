# Nutrition labels (Hassan’s shelf)

**Canonical pack / product macros** for quick Food Logs.  
Homemade pots stay in `recipes.md`. Packaged labels live **here**.

## How to add a label
1. Send a **clear photo of the nutrition table** (and serving size / pieces per pack if shown).
2. Coach saves one block below: **per log unit** (slice, piece, scoop, 100 g).
3. Later you only say e.g. `3 tostas`, `2 Bimbo`, `1 scoop whey` — no retyping.

### Entry template
```
## Brand — product name
- Saved: YYYY-MM-DD · source: label photo / pack
- Log unit: **1 slice / 1 piece / 1 scoop / 100 g**
- Per unit: **kcal · P · C · F** (fiber/salt optional)
- Per 100 g: … (if useful)
- Pack notes: pieces per pack, flavours, Halal, etc.
- Quick log: `N × unit` → multiply per-unit macros
```
